## Verdict

The change is correct and does what it claims. `card_fields` (bin/lean_check.py:582–592) now reads the first 60 lines of `bc._visible(_read(path))` instead of the raw text, and `_visible` blanks while keeping line counts, so the 60-line window stays aligned with `blueprint_check.header_fields` (bin/blueprint_check.py:446–461). The two field regexes are byte-identical (`lc.FIELD_RE.pattern == bc.HEADER_FIELD_RE.pattern` → True; lean_check.py:109, blueprint_check.py:337). On the real artifacts — the fidelity-card template and the pilot card `prop-nstar-interior-ac.md` (read read-only) — the two checkers return identical dicts with all 8 header keys, so no real card regresses. All three suites pass: `py -I bin/test_lean_check.py` 207/207 (including the three new checks `lc_card_fields_skip_comment`, `lc_card_check_passes_with_comment`, `lc_card_fields_skip_fence`), `py -I bin/test_lean_check_integration.py` 16/16, `py -I bin/test_blueprint_check.py` 187/187. Importability holds both ways: `_load_checker()` (lean_check.py:63–73) loads `blueprint_check` by path when run as `py -I bin/lean_check.py` and reuses `sys.modules["blueprint_check"]` when the tests load both, so `bc._visible` resolves identically in both modes (verified: `lc.bc is bc`). Adversarial inputs fail closed where it matters: a header swallowed by a comment (`<!--` closed later in the file) yields `{}` in both checkers and the card check FAILs; a field whose only copy sits inside a closed fence likewise yields `{}` → FAIL; a >60-line comment pushing the header out of the window yields `{}` in both → FAIL; CRLF, BOM and lone-CR files parse correctly. The deductions below are shared, mostly pre-existing semantics of `_visible` that this diff aligns to rather than introduces — none is a regression caused by the diff.

Repro for the probes (scratchpad scripts, re-runnable): write the input bytes to a temp file and compare `lc.card_fields(p)` vs `bc.header_fields(p)`; for the fail-safe checks, run `test_lean_check.setup()` + `lc.check_node(..., statements_only=True)` with the fake runner.
