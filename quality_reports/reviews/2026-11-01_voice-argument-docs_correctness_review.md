## Verdict

The four files implement ADR-0008 consistently with each other on the points the ADR names: `## Argument` heads both the profile and style-model schemas (`voice-profile.md:69`, `:129`); every section count is right (six after `## Argument` for a paper note, three after it for a style model, six for a deck, seven for `writer-critic`); `avoid_vocab` is gone from the schema (`voice-profile.md:63-66`) and no consumer, hook or skill reads it (repo grep: only historical plans, reviews and the session log mention it); the slide schema (`:86-106`) and `storyteller-critic` (`:106-113`) are untouched and correctly so; the precedence rule is restated with the argument exception in the reference (`:116`), `writer.md:104-107` and `writer-critic.md:234`; the ADR-0006 edit is limited to the Status line as `decision-log.md` allows; and none of the four files carries corpus text. The defects are at the seams. The most serious is outside the four files but in the decision they implement: ADR-0008's only Source for its reasoning (`session log § 8`) does not contain that reasoning, so the ADR's required Sources field does not resolve. Within the four files, `writer` is told to follow the *model wins* rules in `style-models.md` while `writer-critic` checks the targets stated in `profile.md`, two texts that can diverge; the "one kind rebuilds only that file" rule now ignores a cross-file dependency the argument level created; the reference's "structure only" bullet list still describes the pre-ADR-0008 scope; and `writer.md` dropped "section structure", leaving the style-model `## Openings` and `## Transitions` sections with no named consumer. None of these is a wrong statement about ADR-0008, but each is a place where a reader following one file would act differently from a reader following another.
